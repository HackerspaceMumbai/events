# Event messaging

Reusable copy for closing slides and follow-up emails. Encourage attendees to preserve the event in the community archive.

---

## Closing slide / follow-up email

Help us preserve the story of this event.

The Hackerspace Mumbai Events Archive is community-maintained.

Have any of the following?

- Photos
- Session Notes
- Key Takeaways
- Event Stories
- Useful Resources

Submit a Pull Request and become part of the event archive.

Repository:

https://github.com/HackerspaceMumbai/events

Speakers contribute knowledge.

Attendees contribute perspective.

Together we build the community archive.

---

## Short version (one slide)

**Help us preserve the story of this event.**

Photos · Notes · Stories · Highlights · Resources

Open a PR: https://github.com/HackerspaceMumbai/events

See [Community contributions](community-contributions.md) for what to share and where files go.
