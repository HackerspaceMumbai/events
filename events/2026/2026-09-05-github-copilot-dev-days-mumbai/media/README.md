# Official event media

This folder is the canonical archive of official event media for Hackerspace Mumbai. It is maintained only by organizers and volunteers, and is intended for consumption by [hackmum.in](https://hackmum.in) for galleries, past-event pages, social content, and recaps.

## Ownership

- `photos/` — official event photography and gallery candidates.
- `videos/` — official recording, highlight-reel, and playlist links. Prefer links over video binaries.
- `social/` — official Hackerspace Mumbai social posts and their supporting assets.

Attendee-created perspectives belong under [`community/`](../community/), including personal photos, notes, stories, highlights, and social posts. Speaker-specific artifacts such as speaker profiles, cards, slides, repositories, and recordings belong under [`speakers/`](../speakers/).

The event cover and optional banner remain directly under this folder and are referenced from `event.yml`.
