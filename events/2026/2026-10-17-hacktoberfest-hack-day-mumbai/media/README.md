# Official event media

Organizer-maintained event photos, videos, social posts, and final published artwork belong here. Keep attendee-submitted perspectives under `community/` and prefer a public gallery link over uploading a bulk photo set.

- [Photos](photos/README.md)
- [Videos](videos/README.md)
- [Social posts](social/README.md)

Final event artwork may be added as `cover.jpg` or `banner.jpg` in this folder. See the [visual assets archival standard](../../../../docs/architecture-and-contracts.md#visual-assets-archival-standard).
